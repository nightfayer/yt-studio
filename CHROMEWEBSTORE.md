# YT Studio — Карточка для Chrome Web Store

## Основная информация

- **Название**: YT Studio — Скачивание видео и аудио
- **Краткое описание**: Скачивание видео, аудио и субтитров с YouTube, Rutube, Twitch, Coub, VK, Zvuk и TikTok без рекламы и внешних серверов.
- **Категория**: Производительность / Утилиты
- **Язык**: Русский (ru)

---

## Подробное описание

YT Studio — автономное расширение для Chromium-браузеров, позволяющее сохранять видео и аудио напрямую в плеере без установки сторонних программ и без отправки ваших ссылок на внешние серверы.

### Главные преимущества:
- **100% автономность**: обработка, перекодирование звука и сборка файлов происходят непосредственно в браузере с помощью современных технологий WebCodecs и WebAssembly FFmpeg.
- **YouTube, Shorts и Music**: скачивание видео вплоть до 4K, извлечение аудио в нативном качестве, MP3 320 кбит/с и M4A 256 кбит/с с обложками, скачивание субтитров (SRT/TXT), сохранение плейлистов и запись прямых трансляций.
- **VK Видео и Клипы**: быстрое скачивание роликов в оригинальном качестве и извлечение звука без необходимости скачивать видеоряд целиком.
- **Rutube и Rutube Sport**: скачивание обычных видео и Shorts.
- **Twitch**: сохранение клипов, VOD-записей и запись прямых эфиров в реальном времени.
- **TikTok и Coub**: сохранение роликов без водяных знаков с оригинальным звуком.
- **Звук (zvuk.com)**: скачивание музыки в высоком битрейте с автоматическими тегами.

## Обоснование разрешений (Permissions Justification)

| Разрешение | Обоснование |
|---|---|
| `downloads` | Необходимо для автоматического сохранения собранных медиафайлов в папку загрузок пользователя. |
| `offscreen` | Требуется для запуска фонового WebAssembly FFmpeg и WebCodecs без блокировки интерфейса активных вкладок. |
| `storage` | Требуется для локального сохранения пользовательских настроек качества плеера и диагностики. |
| `alarms` | Требуется для периодической проверки доступности обновлений расширения. |
| `host_permissions` | Требуется для внедрения кнопок скачивания в интерфейс плееров поддерживаемых видеосервисов и получения медиасегментов. |

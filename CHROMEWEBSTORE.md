*Last Updated: 2026-09-26*

## Detailed Description

YT Studio Companion Extension интегрирует локальный медиа-комбайн YT Studio прямо в ваш браузер.

### Ключевые возможности:
- **Кнопка скачивания прямо в плеере**: аккуратная неоновая кнопка с выпадающим меню встраивается в страницы YouTube (включая Shorts), VK Видео, Rutube и Twitch.
- **Выбор качества на лету**: мгновенный выбор между MP4 (1080p, 720p, 480p) и аудиодорожками (MP3 320 kbps или нативный M4A/AAC).
- **Контекстное меню**: кликните правой кнопкой мыши по любой ссылке или видео, чтобы мгновенно отправить задачу на загрузку.
- **Всплывающее окно (Popup)**: мониторинг статуса локального сервера, быстрая загрузка активной вкладки и просмотр прогресса текущих загрузок в реальном времени.
- **Авто-подключение**: расширение автоматически находит работающий локальный сервер YT Studio (порты 8731–8745) и подключается через защищённый токен.

## Permissions Justification

| Permission | Justification |
|------------|---------------|
| `activeTab` | Требуется для считывания ссылки и заголовка текущей активной страницы при открытии окна расширения и нажатии кнопки «Скачать». |
| `tabs` | Требуется для проверки URL открытых видео-вкладок и открытия веб-панели управления `http://127.0.0.1:8731/` по клику пользователя. |
| `storage` | Требуется для локального сохранения порта обнаруженного сервера YT Studio, токена аутентификации и пользовательских предпочтений качества. Данные не покидают браузер. |
| `contextMenus` | Требуется для добавления команд «Скачать видео в YT Studio» и «Скачать MP3 в YT Studio» в контекстное меню правой кнопки мыши по ссылкам и видео. |
| `alarms` | Требуется для периодической проверки доступности локального сервера YT Studio в фоновом режиме без блокировки потоков. |
| `host_permissions` (`http://127.0.0.1/*`, `http://localhost/*`) | Требуется для взаимодействия с локальным API сервера YT Studio (`/api/status`, `/api/download`, `/api/jobs`). |
| `host_permissions` (`*://*.youtube.com/*`, `*://*.vk.com/*`, `*://*.vkvideo.ru/*`, `*://*.rutube.ru/*`, `*://*.twitch.tv/*`) | Требуется для внедрения content script'а с кнопкой скачивания на страницы поддерживаемых видео-платформ. |

## Privacy Policy & Data Collection

- **Сбор персональных данных**: 0% (расширение не собирает, не хранит и не передаёт никакие персональные данные, историю браузера, файлы cookie или аналитику).
- **Сетевое взаимодействие**: все запросы выполняются исключительно локально между браузером и локальным портом вашего компьютера (`127.0.0.1`). Внешние облачные серверы не используются.
- **Безопасность**: взаимодействие защищено динамическим сессионным токеном (`X-YTS-Token`).

# YT Studio

**Автономное браузерное расширение Chromium для быстрого скачивания видео, аудио, субтитров и записи трансляций — без внешних программ, серверов и рекламы.**

Работает в **Google Chrome**, **Яндекс.Браузере**, **Microsoft Edge**, **Brave**, **Opera** и любых других браузерах на базе Chromium.

## ⚡ Быстрый старт (Установка за 30 секунд)

Вам **не нужны** Python, консоль, `Start.bat` или сторонний софт. Расширение работает целиком внутри браузера.

1. Скачайте свежий архив со страницы [**Релизов на GitHub**](https://github.com/nightfayer/yt-studio/releases/latest) (файл `yt-studio-v2.1.1.zip`) и распакуйте в любую удобную папку (или склонируйте через `git clone`).
2. Откройте в браузере страницу управления расширениями:
   - **Google Chrome / Brave**: `chrome://extensions/`
   - **Яндекс.Браузер**: `browser://tune` или `browser://extensions/`
   - **Microsoft Edge**: `edge://extensions/`
   - **Opera**: `opera://extensions/`
3. В правом верхнем углу включите переключатель **«Режим разработчика»** (*Developer mode*).
4. Нажмите кнопку **«Загрузить распакованное расширение»** (*Load unpacked*).
5. Выберите папку проекта.
6. **Готово!** Теперь на всех поддерживаемых сайтах прямо в плеере появится стильная кнопка скачивания.

## 🎯 Поддерживаемые платформы и возможности

| Платформа | Возможности |
|---|---|
| **YouTube** | Видео в любом разрешении (от 360p до 4K/8K), оригинал без перекодирования или совместимый MP4 (H.264), аудио (**MP3 320k**, **M4A 256k**, Оригинал) с обложкой, субтитры (**SRT**, **TXT**), скачивание плейлистов целиком, запись прямых трансляций с начала эфира. |
| **YouTube Shorts** | Кнопка в панели действий над «Нравится», автоматическая перемотка в начало перед сохранением, выбор качества под мобильный экран. |
| **YouTube Music** | Скачивание треков и клипов, сохранение всей очереди воспроизведения (плейлиста) в один клик. |
| **Instagram** | Скачивание **Reels**, обычных видеопостов и историй в оригинальном качестве без водяных знаков и сторонних ботов, отдельное сохранение аудиодорожки (**MP3**). |
| **VK Видео и Клипы** | Поддержка `vkvideo.ru` и `vk.com/video`, скачивание видео во всех доступных качествах без перекодирования, отдельное извлечение аудиодорожки (M4A / MP3). |
| **Rutube** | Поддержка `rutube.ru` и `rutube.sport`, обычные видео и вертикальные Shorts, скачивание без апскейлинга. |
| **Twitch** | Скачивание клипов и полных записей трансляций (VOD), запись прямых трансляций в реальном времени. |
| **TikTok** | Скачивание видео **без водяных знаков** в максимальном доступном разрешении, отдельное сохранение аудиодорожки. |
| **Coub** | Скачивание коубов с полным звуком (зацикленное видео или один проход) без водяных знаков. |
| **Звук (zvuk.com)** | Скачивание треков в MP3 320 кбит/с с правильными тегами («Артист - Название») и сохранение целых альбомов. |

## 🛠 Технологии под капотом

- **Хук плеера в реальном времени**: Расширение перехватывает медиапотоки непосредственно в контексте страницы плеера. Видео расшифровывается самим браузером в процессе просмотра — никакой капчи или блокировок InnerTube.
- **Аппаратное ускорение через WebCodecs**: Склейка и кодирование видеопотоков осуществляются силами вашего графического процессора (GPU) через браузерный API `WebCodecs` (библиотека `MediaBunny`), что в разы быстрее реального времени.
- **Встроенный WebAssembly FFmpeg (`ffmpeg.wasm`)**: Для сложных операций со звуком и медиаконтейнерами используется скомпилированное WebAssembly-ядро FFmpeg, работающее в скрытом `offscreen`-документе без блокировки интерфейса вкладки.
- **Дисковая буферизация (OPFS)**: Сегменты видео и прямых эфиров сохраняются напрямую во временную файловую систему браузера на диске (*Origin Private File System*), благодаря чему вкладка не вылетает из-за нехватки оперативной памяти.
- **100% приватность**: Все операции производятся исключительно на вашем компьютере. Видео и ссылки никогда не отправляются на сторонние серверы.

## ⚙️ Новые возможности и настройки (v2.0)

При клике на значок расширения в панели браузера открывается меню:
- **Индикатор активных загрузок**: отображение текущего прогресса сборки и скачивания файла прямо в окне расширения.
- **Качество плеера по умолчанию**: автоматический выбор разрешения под ваш монитор для **YouTube**, **Twitch**, **VK Видео** и **Rutube**.
- **Запрет автоматического понижения качества**: защита от падения битрейта при нестабильной сети.
- **Шаблон имени файла**: выбор между «Только название» и «Автор — Название».
- **Быстрый доступ по горячей клавише**: нажмите **`Alt + Shift + D`** на любой странице с видео для моментального открытия меню скачивания.
- **Вкладки фильтрации**: переключение `[ Все ] [ Видео ] [ Аудио ] [ Субтитры ]` прямо в меню плеера для быстрой навигации.
- **Диагностика и восстановление**: аккуратный сворачиваемый раздел отладки и экспорт отчёта `YTS-debug.txt`.

## 🔄 Обновление расширения

Расширение оснащено встроенным фоновым модулем проверки обновлений через GitHub:
- При выходе новой версии на иконке расширения в панели браузера автоматически загорается бирюзовый бейдж **`+`**, а в меню открывается прямая ссылка на скачивание свежего релиза.
- **Для пользователей ZIP-архива**: скачайте файл `yt-studio-vX.X.zip` со страницы [Релизов](https://github.com/nightfayer/yt-studio/releases/latest), распакуйте его в папку расширения с заменой файлов и нажмите кнопку **🔄 (Обновить)** на странице `chrome://extensions/`.
- **Для пользователей Git**: выполните в папке расширения команду `git pull` и нажмите **🔄 (Обновить)** в `chrome://extensions/`.

· обход проверки на бота · 5 цветовых тем · доступ со смартфона по Wi-Fi · без внешних зависимостей

## Быстрый старт

### Windows

1. Скачайте архив проекта (кнопка **Code → Download ZIP**) и распакуйте в любую папку.
2. Двойной клик по **`Start.bat`**.
3. Браузер откроется сам.

Нужен только **Python 3.8 или новее**. Если его нет, скрипт покажет команду установки:

```
winget install -e --id Python.Python.3.12
```

или скачайте установщик с [python.org](https://www.python.org/downloads/) — при установке обязательно отметьте галочку **Add python.exe to PATH**.

`yt-dlp`, `FFmpeg` и компонент обхода DPI (`ciadpi`) приложение скачает само при первом запуске в папку `bin/`. Интернет для этого нужен один раз — дальше папку можно переносить на флешке и запускать автономно.

### Доступ с телефона (домашний Wi-Fi)

1. Запустите `Start.bat` на компьютере.
2. В правом верхнем углу интерфейса нажмите кнопку **«📱 Телефон (Wi-Fi)»** — адрес скопируется в буфер обмена (также он выводится в консоли, например: `http://192.168.1.5:8731/`).
3. Откройте эту ссылку в браузере смартфона или планшета в той же сети Wi-Fi.
4. Вы сможете управлять загрузками и сохранять готовые файлы прямо в память телефона.

### Linux / macOS

```bash
git clone https://github.com/nightfayer/yt-studio.git
cd yt-studio
chmod +x start.sh
./start.sh
```

FFmpeg устанавливается системным менеджером пакетов:

```bash
sudo apt install ffmpeg      # Debian / Ubuntu
brew install ffmpeg          # macOS
```

## Как пользоваться

1. Вставьте ссылку вручную или нажмите кнопку **«📋 Вставить»** — поиск запустится автоматически.
2. Сервис определит платформу (YouTube, VK, Rutube, Twitch, Coub и т.д.) и покажет предпросмотр ролика.
3. Выберите нужный режим:
   - **Видео (MP4)** — укажите разрешение (от 360p до 4K), при необходимости включите **H.264** или **Субтитры**.
   - **Аудио (MP3 / M4A)** — выберите битрейт и нужный формат (универсальный MP3 или нативный M4A для Apple).
4. Нажмите **Скачать**.

В карточке загрузки виден живой статус, скорость, объём и шкала с неоновым бликом:
- Кнопка с **иконкой папки** открывает скачанный файл в Проводнике Windows.
- Кнопка со **стрелкой скачивания** загружает файл через браузер на текущее устройство (компьютер или телефон).
- Кнопка с **терминалом** разворачивает подробный цветной лог yt-dlp с кнопкой «Копировать».
- Иконка шестерёнки в шапке открывает выбор тем, настройки звуков, выбор папки, настройки обхода DPI и кнопку обновления yt-dlp.

## Структура проекта

```
app.py           локальный сервер, только стандартная библиотека Python
index.html       интерфейс со стилями, Web Audio, Canvas FX и темами
Start.bat        лаунчер для Windows (локальный запуск и Wi-Fi)
start.sh         лаунчер для Linux и macOS
bin/             yt-dlp, ffmpeg и ciadpi — скачиваются автоматически, в git не попадают
downloads/       папка сохранённых файлов по умолчанию
config.json      конфигурация пользователя (папка, тема, звуки, прокси, куки)
history.json     история завершённых загрузок
```

Внешних зависимостей нет: ни `pip install`, ни `node_modules`, ни CDN. Всё работает полностью автономно и локально.

## Безопасность и архитектура

- **Защита API**: Каждая сессия защищена уникальным криптографическим токеном (`X-YTS-Token`) и cookie `SameSite=Strict`. Сторонние сайты не могут отправлять команды на ваш локальный сервер.
- **Ограничение хостов**: Разрешены только локальные обращения (`127.0.0.1`, `localhost`) и домашняя локальная сеть (`192.168.x.x`, `10.x.x.x`, `172.16-31.x.x`).
- **Чистота диска**: Временные файлы загружаются в `.tmp/<job>` и автоматически вычищаются при завершении, отмене или перезапуске приложения.

## Частые вопросы

**Как открыть приложение на телефоне?**  
Убедитесь, что телефон подключён к той же сети Wi-Fi, что и компьютер. Нажмите на ПК кнопку **«📱 Телефон (Wi-Fi)»** в правом верхнем углу интерфейса или введите адрес из окна консоли (например, `http://192.168.1.5:8731/`).

**Ошибка «Sign in to confirm you’re not a bot» (проверка на бота).**  
В YT Studio уже встроен автоматический обход через мобильные клиенты iOS и Mobile Web (`player_client=default,ios,mweb`). Если же ролик имеет строгое возрастное ограничение 18+ или доступен только по закрытой ссылке:
1. Положите файл `cookies.txt` (экспортированный через расширение вроде «Get cookies.txt LOCALLY») в папку приложения рядом со `Start.bat`.
2. Либо в Настройках (шестерёнка) выберите ваш браузер в пункте «Cookies браузера» (браузер должен быть закрыт во время скачивания).

**Видео перестало скачиваться / ошибка видеосервиса.**  
Видеоплатформы регулярно обновляют свои алгоритмы. Откройте настройки ⚙️ и нажмите **«Обновить yt-dlp»** — утилита обновится до самой свежей версии без перезапуска приложения.

**Антивирус ругается на `bin/yt-dlp.exe` или `ciadpi.exe`.**  
Это стандартная ложная тревога эвристики для упакованных бинарников. Файлы загружаются напрямую с официальных GitHub-релизов yt-dlp и ByeDPI.

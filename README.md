# YT Studio

**Портативный загрузчик видео с YouTube и извлечение MP3 — с современным интерфейсом в браузере.**

Видео в любом доступном качестве до 4K/8K · MP3 от 64 до 320 kbps · живой график скорости
· доступ со смартфона по домашнему Wi-Fi · без установки зависимостей вручную

## Быстрый старт

### Windows

1. Скачайте архив проекта (кнопка **Code → Download ZIP**) и распакуйте в любую папку.
2. Двойной клик по **`Start.bat`**.
3. Браузер откроется сам.

Нужен только **Python 3.8 или новее**. Если его нет, скрипт покажет команду установки:

```
winget install -e --id Python.Python.3.12
```

или скачайте установщик с [python.org](https://www.python.org/downloads/) — при установке обязательно отметьте галочку **Add python.exe to PATH**.

`yt-dlp` и `FFmpeg` приложение скачает само при первом запуске и положит в папку `bin/`. Интернет для этого нужен один раз — дальше папку можно переносить на флешке.

### Доступ с телефона (домашний Wi-Fi)

1. Запустите `Start.bat` на компьютере.
2. В правом верхнем углу интерфейса нажмите кнопку **«📱 Телефон (Wi-Fi)»** — адрес скопируется в буфер обмена (также он выводится в окне консоли, например: `http://192.168.1.5:8731/`).
3. Откройте эту ссылку в браузере смартфона или планшета, подключённого к той же сети Wi-Fi.
4. Вы сможете управлять загрузками и сохранять готовые файлы прямо на телефон по кнопке скачивания.

### Удалённый доступ через интернет (вне дома)

Если вам нужно поставить загрузку или скачать видео, находясь вне дома (через мобильный интернет 4G/5G):

1. Убедитесь, что `Start.bat` запущен.
2. Запустите **`Share-Online.bat`**.
3. Скрипт создаст защищённый HTTPS-туннель Cloudflare и выдаст персональную ссылку вида `https://xxxx.trycloudflare.com`.
4. Перейдите по этой ссылке на любом устройстве. Никаких белых IP и настроек роутера не требуется.

### Linux / macOS

```bash
git clone https://github.com/nightfayer/yt-studio.git
cd yt-studio
chmod +x start.sh
./start.sh
```

FFmpeg здесь ставится системным менеджером пакетов:

```bash
sudo apt install ffmpeg      # Debian / Ubuntu
brew install ffmpeg          # macOS
```

`yt-dlp` по-прежнему скачивается автоматически.

## Возможности

| | |
|---|---|
| **Любое качество** | Список разрешений строится из форматов, реально доступных для конкретного видео — от 144p до 4K/8K, с пометками HD/2K/4K и 60 fps |
| **MP3 или оригинал M4A** | Выбор битрейта MP3 (64–320 kbps) или оригинальный поток M4A/Opus без перекодирования (без потерь и мгновенно) |
| **Доступ со смартфона** | Поддержка управления и скачивания файлов на телефон или планшет по домашней сети Wi-Fi или через защищённый туннель |
| **Скачивание на устройство** | Кнопка со стрелочкой на карточке загрузки позволяет сразу сохранить готовый MP4/MP3 файл в память телефона или ПК через браузер |
| **Встроенный обход DPI** | Встроенный микро-прокси с фрагментацией TLS ClientHello для обхода ТСПУ и замедления YouTube напрямую без внешних VPN, многопоточный чанкинг (10 МБ) и выбор клиентов (Android/iOS) |
| **Cookies из браузера** | Авторизация через Chrome, Edge, Firefox и др. для скачивания 18+ и закрытых видео |
| **Субтитры** | Опция автоматического скачивания и встраивания субтитров (русские и английские) |
| **Выбор папки через проводник** | Нативная кнопка «Обзор...» для быстрого выбора каталога сохранения |
| **Живая скорость и SSE** | Обновления в реальном времени через Server-Sent Events (SSE), живой график скорости и системные уведомления браузера |
| **Гарантия звука** | Для MP4 запрашивается AAC-дорожка; если YouTube отдал только Opus, звук перекодируется, а результат проверяется через `ffprobe` |
| **Совместимый кодек** | Переключатель H.264 — для старых плееров, телевизоров и монтажных программ |
| **Плейлисты** | Ссылка со списком предлагает скачать все видео в отдельную папку с нумерацией |
| **Очередь и история** | До трёх параллельных загрузок, отмена, сохранение истории в `history.json` между перезапусками |
| **Русские имена файлов** | Названия сохраняются как есть, вырезаются только символы, запрещённые в Windows |

## Как пользоваться

1. Вставьте ссылку — поиск запустится автоматически.
2. Выберите **Видео (MP4)** или **Аудио (MP3 / M4A)**.
3. Выберите качество, при необходимости включите **H.264** или **Субтитры**.
4. Нажмите **Скачать**.

В строке загрузки видно этап, скорость, размер и остаток времени:
- Кнопка с **иконкой папки** открывает скачанный файл в Проводнике на компьютере.
- Кнопка со **стрелкой скачивания** загружает файл через браузер прямо на текущее устройство (удобно для смартфона).
- Если загрузка завершилась с ошибкой, кнопка с журналом покажет подробный лог yt-dlp.

Иконка шестерёнки — выбор папки («Обзор...»), настройки сети и обхода DPI, Cookies браузера и кнопка **Обновить yt-dlp**.

## Структура проекта

```
app.py           локальный сервер, только стандартная библиотека Python
index.html       интерфейс (один файл: разметка, стили, скрипты)
Start.bat        лаунчер для Windows (локальный запуск и Wi-Fi)
Share-Online.bat лаунчер Cloudflare Tunnel для удалённого доступа через интернет
start.sh         лаунчер для Linux и macOS
bin/             yt-dlp, ffmpeg и утилиты — создаётся автоматически, в git не попадает
downloads/       скачанные файлы
config.json      настройки пользователя (папка, прокси, куки, клиент)
history.json     история завершённых загрузок
```

Внешних зависимостей нет: ни `pip install`, ни `node_modules`. Только Python из системы.

## Как это устроено

`app.py` поднимает HTTP-сервер, занимая первый свободный порт из диапазона **8731–8780** (адрес печатается в окне консоли), и отдаёт `index.html`. Интерфейс общается с ним через JSON API, а сервер вызывает `yt-dlp` как отдельный процесс и разбирает его вывод через `--progress-template`, получая точные числа: скачанные байты, общий размер, скорость и ETA.

Прогресс видео честно разложен на этапы: yt-dlp качает видеопоток и аудиодорожку отдельными проходами, поэтому шкала не откатывается назад, а делится на слоты — видео 0–70 %, аудио 70–92 %, склейка и теги 92–100 %.

### Безопасность

Сервер доступен локально и в пределах вашей домашней подсети:

- API защищён уникальным токеном сессии (`X-YTS-Token` и query-параметром `?token=...`) и cookie `SameSite=Lax; HttpOnly` — сторонний веб-сайт не сможет слать запросы к вашему приложению;
- проверяются заголовки `Host` (разрешены loopback `127.0.0.1`, `localhost`, локальные домашние подсети `192.168.x.x`, `10.x.x.x`, `172.16-31.x.x` и защищённые домены `*.trycloudflare.com`) и заголовок `Origin`;
- смена папки сохранения требует абсолютного пути и проверяется пробной записью.

### Чистота папки

Незавершённые загрузки идут в `.tmp/<job>` через `-P temp:` и удаляются при отмене, при старте и при остановке сервера. Мусорных `.part`-файлов среди готовых видео не остаётся.

## Частые вопросы

**Как открыть приложение на телефоне?**
Убедитесь, что телефон подключён к той же домашней сети Wi-Fi, что и компьютер. Нажмите на ПК кнопку **«Телефон (Wi-Fi)»** в правом верхнем углу интерфейса или введите адрес из окна консоли (например, `http://192.168.1.5:8731/`). Для доступа вне дома используйте `Share-Online.bat`.

**Антивирус ругается на `bin/yt-dlp.exe`.**
Это нормальная ложная тревога для упакованных PyInstaller-бинарников. Файл скачивается напрямую с [официальных релизов yt-dlp на GitHub](https://github.com/yt-dlp/yt-dlp/releases) — ссылку видно в `app.py`.

**Видео перестало скачиваться / ошибка про формат.**
YouTube периодически меняет внутренние API. Откройте настройки и нажмите **Обновить yt-dlp**.

**Видео скачалось без звука.**
Не должно происходить: звук приводится к AAC и проверяется. Если случилось — обновите yt-dlp и пришлите журнал из карточки задачи.

**Порт занят.**
Сервер сам переберёт диапазон 8731–8780. Изменить его можно в константе `PORT_RANGE` в `app.py`.

**Можно ли собрать `.exe`?**
Да, `pyinstaller --onefile --add-data "index.html;." app.py`, но смысла мало: приложение и так не требует установки, а антивирусы к самосборным exe относятся хуже, чем к обычному скрипту.

**Портативный загрузчик видео с YouTube и извлечение MP3 — с современным интерфейсом в браузере.**

· плейлисты · без установки зависимостей вручную

## Быстрый старт

### Windows

1. Скачайте архив проекта (кнопка **Code → Download ZIP**) и распакуйте в любую папку.
2. Двойной клик по **`Start.bat`**.
3. Браузер откроется сам.

Нужен только **Python 3.8 или новее**. Если его нет, скрипт покажет команду установки:

```
winget install -e --id Python.Python.3.12
```

или скачайте установщик с [python.org](https://www.python.org/downloads/) — при установке обязательно отметьте галочку **Add python.exe to PATH**.

`yt-dlp` и `FFmpeg` приложение скачает само при первом запуске и положит в папку `bin/`. Интернет для этого нужен один раз — дальше папку можно переносить на флешке.

### Linux / macOS

```bash
git clone https://github.com/nightfayer/yt-studio.git
cd yt-studio
chmod +x start.sh
./start.sh
```

FFmpeg здесь ставится системным менеджером пакетов:

```bash
sudo apt install ffmpeg      # Debian / Ubuntu
brew install ffmpeg          # macOS
```

`yt-dlp` по-прежнему скачивается автоматически.

## Возможности

| | |
|---|---|
| **Любое качество** | Список разрешений строится из форматов, реально доступных для конкретного видео — от 144p до 4K/8K, с пометками HD/2K/4K и 60 fps |
| **MP3 64–320 kbps** | Полный диапазон битрейтов; исходный битрейт дорожки YouTube показан отдельно, значения выше него помечены точкой |
| **Живая скорость** | Скорость, скачанный объём, общий размер и остаток времени обновляются дважды в секунду, рядом — график скорости за последние ~20 секунд |
| **Гарантия звука** | Для MP4 запрашивается AAC-дорожка; если YouTube отдал только Opus, звук перекодируется, а результат проверяется через `ffprobe` |
| **Совместимый кодек** | Переключатель H.264 — для старых плееров, телевизоров и монтажных программ |
| **Плейлисты** | Ссылка со списком предлагает скачать все видео в отдельную папку с нумерацией |
| **Очередь** | До трёх параллельных загрузок, отмена, журнал ошибок yt-dlp по кнопке |
| **Русские имена файлов** | Названия сохраняются как есть, вырезаются только символы, запрещённые в Windows |

## Как пользоваться

1. Вставьте ссылку — поиск запустится автоматически.
2. Выберите **Видео (MP4)** или **Аудио (MP3)**.
3. Выберите качество, при необходимости включите **H.264**.
4. Нажмите **Скачать**.

В строке загрузки видно этап, скорость, размер и остаток времени. Готовый файл открывается кнопкой с иконкой папки; если загрузка упала, та же кнопка показывает журнал yt-dlp.

Иконка шестерёнки — папка сохранения и кнопка **Обновить yt-dlp**. По умолчанию файлы идут в `downloads/`.

## Структура проекта

```
app.py           локальный сервер, только стандартная библиотека Python
index.html       интерфейс (один файл: разметка, стили, скрипты)
Start.bat        лаунчер для Windows
start.sh         лаунчер для Linux и macOS
bin/             yt-dlp и ffmpeg — создаётся автоматически, в git не попадает
downloads/       скачанные файлы
config.json      настройки пользователя
```

Внешних зависимостей нет: ни `pip install`, ни `node_modules`. Только Python из системы.

## Как это устроено

`app.py` поднимает HTTP-сервер на `127.0.0.1`, занимая первый свободный порт из диапазона **8731–8780** (адрес печатается в окне консоли), и отдаёт `index.html`. Интерфейс общается с ним через небольшой JSON API, а сервер вызывает `yt-dlp` как отдельный процесс и разбирает его вывод через `--progress-template`, получая точные числа: скачанные байты, общий размер, скорость и ETA.

Прогресс видео честно разложен на этапы: yt-dlp качает видеопоток и аудиодорожку отдельными проходами, поэтому шкала не откатывается назад, а делится на слоты — видео 0–70 %, аудио 70–92 %, склейка и теги 92–100 %.

### Безопасность

Сервер слушает только localhost, но этого мало: любая открытая в браузере страница может отправить запрос на `127.0.0.1`. Поэтому:

- API защищён токеном сессии (`X-YTS-Token`) и cookie с `SameSite=Strict; HttpOnly` — сторонний сайт не получит ни того, ни другого;
- проверяются заголовки `Host` (только loopback) и `Origin`;
- смена папки сохранения требует абсолютного пути и проверяется пробной записью.

### Чистота папки

Незавершённые загрузки идут в `.tmp/<job>` через `-P temp:` и удаляются при отмене, при старте и при остановке сервера. Мусорных `.part`-файлов среди готовых видео не остаётся.

## Частые вопросы

**Антивирус ругается на `bin/yt-dlp.exe`.**
Это нормальная ложная тревога для упакованных PyInstaller-бинарников. Файл скачивается напрямую с [официальных релизов yt-dlp на GitHub](https://github.com/yt-dlp/yt-dlp/releases) — ссылку видно в `app.py`.

**Видео перестало скачиваться / ошибка про формат.**
YouTube периодически меняет внутренние API. Откройте настройки и нажмите **Обновить yt-dlp**.

**Видео скачалось без звука.**
Не должно происходить: звук приводится к AAC и проверяется. Если случилось — обновите yt-dlp и пришлите журнал из карточки задачи.

**Порт занят.**
Сервер сам переберёт диапазон 8731–8780. Изменить его можно в константе `PORT_RANGE` в `app.py`.

**Можно ли собрать `.exe`?**
Да, `pyinstaller --onefile --add-data "index.html;." app.py`, но смысла мало: приложение и так не требует установки, а антивирусы к самосборным exe относятся хуже, чем к обычному скрипту.
